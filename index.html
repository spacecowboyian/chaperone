Guided tours for responsive web sites and applications.

chaperone.js is a lightweight, dependency-free script for walking users through your app or site, at any screen size. You decide what shows up on mobile vs. desktop.

  • Lightweight: no runtime dependencies, ships as ESM or a single <script> tag
  • Responsive: you name the breakpoints, steps can be shown/hidden per size
  • Flexible: bring your own markup, or restyle the default theme with CSS variables

Install

npm install chaperonejs

As an ES module (bundlers, modern apps)

import chaperone from 'chaperonejs';
import 'chaperonejs/theme.css';

chaperone.init(tour);

As a plain <script> tag

<link rel="stylesheet" href="node_modules/chaperonejs/dist/chaperone.css">
<script src="node_modules/chaperonejs/dist/chaperone.min.js"></script>
<script>
  chaperone.init(tour);
</script>

Usage

Create a tour object

const tour = {
    // Name your own breakpoints, generic is best.
    breakpoints: {
        mobile: 420,
        mobileLandscape: 740,
        tablet: 1024
    },
    // Start the tour as soon as init() runs.
    autoStart: false,
    // Bring your own markup for the throbber and/or the chaperone bubble.
    throbberHTML: 'your fancy html here',
    chaperoneHTML: 'more fanciness',
    // Selectors inside chaperoneHTML, if you replaced it.
    progressSelector: '[data-hook="chaperone-progress"]',
    textSelector: '[data-hook="chaperone-text"]',
    backSelector: '[data-hook="chaperone-back"]',
    nextSelector: '[data-hook="chaperone-next"]',
    finishSelector: '[data-hook="chaperone-finish"]',
    // How fast should things move (ms)?
    animationTime: 300,
    // Called once the tour finishes.
    finishCallback: () => {},
    steps: [
        {
            // Defaults to 'body' if there's no target selector.
            target: '[data-hook="nav-what"]',
            // 'none' (absolute), 'locked' (absolute to the target's container),
            // or 'fixed' (fixed to the window).
            position: 'locked',
            // When locked, control the throbber's distance from the target.
            lockedLeft: 100,
            lockedTop: -30,
            // Required: what does this step say?
            message: 'Well... it\'s where we tell you what this thing is.',
            // Optional open/close callbacks.
            openEvent: openMenu,
            closeEvent: closeMenu,
            // Which breakpoints show this step? Defaults to all of them.
            shownOn: ['mobile', 'tablet']
        }
    ]
};

Launch that tour!

chaperone.init(tour);

Theming

The default theme is light-popup-on-dark-page by design, with a warm gold accent — built entirely with CSS custom properties. Override any of them to match your site — nothing else needs to change.

:root {
    --chaperone-bg: #111111;
    --chaperone-fg: #f4f4f4;
    --chaperone-accent: #0ea5e9;
    --chaperone-radius: 4px;
}
